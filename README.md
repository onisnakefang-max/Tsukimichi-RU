# Tsukimichi RU — журнал заданий FFXIV

Русская сборка плагина Tsukimichi для Dalamud. Локализация охватывает все 4 868 строк интерфейса; перевод остаётся черновым до проверки носителем языка.

## Установка

1. В игре введите `/xlsettings` и откройте вкладку **Experimental**.
2. В **Custom Plugin Repositories** вставьте в пустую строку:
   `https://raw.githubusercontent.com/onisnakefang-max/Tsukimichi-RU/main/pluginmaster.json`
3. Нажмите **+**, включите репозиторий галочкой и нажмите **Save and Close**.
4. Введите `/xlplugins`, найдите **Tsukimichi** и нажмите **Install**.

Обновления будут приходить через Dalamud. Исходный проект — [xenofei/Tsukimichi](https://github.com/xenofei/Tsukimichi), автор Michiru Tsukikage; лицензия MIT.
